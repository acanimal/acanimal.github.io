Create a map of the earth isn't an easy problem. Projections basically tries to solve the problem of how to 3D element on a 2D surface.

Tons of papers have been written about this problem but a nice place to start is the wikipedia entry about [Map Projections](http://en.wikipedia.org/wiki/Map_projection).

![Cylindrical projection](@/content/posts/images/Usgs_map_miller_cylindrical.PNG)

Some time ago I seen a awesome video from the project [Unfolding the Earth: Myriahedral Projections](http://www.win.tue.nl/~vanwijk/myriahedral/). On it, the author divides the sphere into a myriahedron (a [polyhedron](http://en.wikipedia.org/wiki/Polyhedron) with a very large number of faces) which allows to unfold the sphere in many different map projections.

![Unfolding the Earth - Myriahedral projections](@/content/posts/images/Unfolding-the-Earth-Myriahedral-projections1.png)

Recently I could seen another nice experiment at the [bl.ocks.org](http://bl.ocks.org/) site. The [Projection Transitions](http://bl.ocks.org/3711652) is an great map work example implemented with [D3.js](http://d3js.org/) library which shows an animated transition of map projections.

![Projection Transitions](@/content/posts/images/Projection-Transitions-300x298.png)
